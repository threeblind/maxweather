# 日次ダイジェスト 自動確認・編集・公開フロー

毎晩0時、AIが前日のレースを振り返るダイジェスト記事を自動で生成・校正・公開します。

## フロー図

```
00:00 自動起動
  │
  ├─ 0. AIによる記事生成
  │   OpenAIのAPIで、当日のデータをもとに
  │   ダイジェスト記事を自動生成する
  │
  ├─ ① 機械チェック
  │   記事を自動で検査（日付、数字の誤り、未変換の文字など）
  │   ├─ 異常あり → 自動修正してやり直し
  │   └─ 異常なし → ②へ
  │
  ├─ ② AIによる編集
  │   事実関係の確認（順位・距離・選手名の誤り）
  │   スポーツ実況風のスタイル編集（熱量アップ！）
  │   記事ファイルを更新
  │
  ├─ ③ 最終チェック → 公開
  │   もう一度全体を検査
  │   ├─ OK → GitHubに自動保存・公開、完了報告
  │   ├─ 記事に問題 → ②に戻って修正（最大3回）
  │   └─ システムエラー → 停止して報告
  │
  └─ 最大3回のループで打ち切り
```

## 各ステップの説明

### ① 機械チェック
ルールベースで記事の品質をチェックします：
- 日付が正しいか
- 距離の表記が壊れていないか（例：「39.km」のような誤り）
- テンプレートの未置換がないか
- 実データと距離が一致しているか
- 存在しないチーム名が使われていないか
- タスキリレーの記述で同じ選手が「AからAへ」と書かれていないか
- 記事以外のファイルに予期しない変更がないか

### ② AIによる編集（推敲＋スタイル編集）
AIが以下の観点で記事を確認・編集します：
- 区間の混同がないか
- 距離・順位の数値は正しいか
- 選手とチームの対応が正しいか
- タスキリレーの記述が正しいか（異なる選手間のリレーになっているか）
- 文章が自然で読みやすいか

**さらに、常にスポーツ実況風のスタイル編集を適用します：**
- 実況解説者らしい熱量のある文体に
- 「！」「？」などでリズムを付ける
- 見出しにキャッチーなフレーズを加える
- ただし事実情報（距離・順位・選手名・チーム名）は厳守

### ③ 最終チェック＋公開
もう一度①と同じ機械チェックを実行し、すべて合格すればGitHubに自動保存・公開します。

記事に問題があれば②に戻って修正（最大3回まで）。システムエラー（予期しないファイル変更など）の場合は安全のため停止します。

## 制約
- AI未応答の日は無理に記事を作らない
- 事実の変更・推測は禁止
- 最大3回のループで打ち切り
